# Conversor Moedas

> Conversor de moedas com frontend em React e backend PHP, containerizado com Docker Compose. Consome API de cotacoes em tempo real.

## Stack

- Docker

## Prerequisitos

- Docker e Docker Compose

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/conversor-moedas.git
cd conversor-moedas

# Inicie a aplicacao
docker-compose up -d
```
